# Sales Performance & Revenue Analysis Dashboard

## 📌 Overview
An Excel-based analysis project evaluating sales trends, category distribution, and department-wise revenue using statistical calculations, data cleaning, and interactive Pivot Tables.

---

## 🔑 Key Features & Deliverables
- **Data Cleaning & Preparation:** Formatted raw data, handled missing entries, and eliminated duplicates.
- **Descriptive Statistics:** Calculated Mean, Median, Mode, and Variance to assess revenue distribution.
- **Pivot Table Dashboard:** Interactive visual summarization tracking:
  - Total Revenue
  - Sales by Category
  - Yearly Sales Trends
  - Department-wise Revenue Breakdown

---

## 🛠️ Tools & Skills
- **Excel Capabilities:** Grid Navigation, Data Types, Pivot Tables, Slicers.
- **Formulas:** `SUM`, `AVERAGE`, `COUNT`, `COUNTA`.
